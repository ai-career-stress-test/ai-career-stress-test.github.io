# AI Career Stress Test

Test how exposed any job is to AI and robots, task by task, and get a plan to stay relevant.

Take the test: https://ai-career-stress-test.github.io/

- **Use any AI:** copy a ready-made prompt into ChatGPT, Gemini, Copilot, Claude, Muse or any assistant, then paste the answer back to score and compare AIs.
- **Score it yourself:** answer four quick questions about each task. No account needed.
- Installable on phones and computers, and works offline after the first visit.
